# MiniOS Alpha — User Manual

## 1. Introduction
MiniOS Alpha is a command-line operating system simulator developed using Python. It allows users to explore basic operating system functions through text commands.

## 2. System Requirements
- Windows operating system
- Python 3
- Visual Studio Code (optional)

## 3. How to Run the Program
1. Open Visual Studio Code.
2. Open the MiniOS project folder.
3. Open the terminal in VS Code.
4. Type `py main.py`.
5. Press Enter to start MiniOS.

## 5. Available Commands
- `help` — Displays available commands.
- `clear` — Clears the terminal screen.
- `date` — Displays the current date.
- `time` — Displays the current time.
- `whoami` — Displays the current username.
- `systeminfo` — Displays simulated system information.
- `dir` — Lists files and folders.
- `mkdir` — Creates a folder.
- `create` — Creates a file.
- `read` — Reads a file.
- `write` — Writes or updates file contents.
- `delete` — Deletes a file.
- `process` — Displays running processes.
- `run` — Starts a simulated process.
- `kill` — Terminates a simulated process.
- `memory` — Displays memory information.
- `allocate` — Allocates simulated memory.
- `free` — Releases allocated memory.
- `exit` — Exits MiniOS.

## 6. Error Handling
Users should enter valid commands and provide the required information. Type `help` to view available commands.

## 7. Limitations
MiniOS Alpha is an educational simulator, not a real operating system. File, process, and memory operations are simulated. Some functions may vary depending on the implemented code.

## 8. Conclusion
MiniOS Alpha demonstrates basic operating system concepts through a command-line interface, including login, file management, process management, and memory management.
